# 1c_agentic_sdlc

Общий процесс разработки 1С с агентом: постановка Jira, план, реализация,
ревью и доставка. Для задачи можно использовать обычную ветку или отдельный Git worktree.
Выбор зависит от удобства работы, состояния папки и правил проекта.

## Состав

- [AGENTS.md](AGENTS.md) — короткая основа правил для проекта 1С.
- [av-1c-agentic-sdlc](.agents/skills/av-1c-agentic-sdlc/SKILL.md) — общий процесс и документы задачи.
- [bsl-analyzer.toml](bsl-analyzer.toml) — состав СММ: CF и десять расширений.
- [Готовые MCP-настройки](mcp/configs) — общие серверы, четыре проекта и worktree DEV1C-33021.
- [configure_mcp.py](scripts/configure_mcp.py) — проверка и применение настроек для обычной папки или worktree.

Этот репозиторий содержит правила, навык и готовые настройки инструментов.
Исходников прикладной конфигурации здесь нет.
Пути `src` и `tasks` в AGENTS.md относятся к проекту, в котором он применяется.

## Применение в проекте

1. Перенеси `.agents/skills/av-1c-agentic-sdlc` в проект либо установи навык в личный каталог ниже.
2. Адаптируй AGENTS.md: сохрани действующие ограничения проекта, добавь его базовую ветку, upstream, workspace анализатора и порядок работы с ветками и worktree. Не заменяй существующие правила без сверки.
3. При личной установке замени относительную ссылку на SKILL.md в проектном AGENTS.md действующим путём установленного навыка.
4. Для СММ используй готовый `bsl-analyzer.toml`. Для другого проекта сверь состав его конфигураций и расширений.
5. Прочитай раздел настройки MCP в навыке. Выбери Codex, Claude Code или нативный pi.
6. Выполни проверку путей. Затем примени настройки выбранного клиента.

Wrapper-скрипты worktree не входят в этот репозиторий. Навык использует
доступный механизм конкретного проекта. Команды СММ приведены как условный пример.

## Личная установка и обновление

Из локальной копии этого репозитория в PowerShell:

```powershell
$skillSource = Join-Path (Get-Location) '.agents\skills\av-1c-agentic-sdlc'
$skillRoot = Join-Path $env:USERPROFILE '.agents\skills'
New-Item -ItemType Directory -Path $skillRoot -Force | Out-Null
Copy-Item -LiteralPath $skillSource -Destination $skillRoot -Recurse -Force
```

Команда устанавливает навык или заменяет одноимённые файлы установленной версии.
Перед обновлением сохрани собственные изменения навыка. Личная установка нужна
только один раз для нескольких проектов; автоматической синхронизации нет.

Вызывать явно: `$av-1c-agentic-sdlc`. Если клиент ещё не обнаружил установленный
навык, укажи абсолютный путь к его SKILL.md.

Общие изменения навыка веди в этом репозитории, затем обновляй личную копию.
Особенности конфигурации, баз и доставки оставляй в AGENTS.md соответствующего проекта.
