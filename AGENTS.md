# Правила проекта 1С

Для задач разработки 1С используй навык `av-1c-agentic-sdlc`:
[SKILL.md](.agents/skills/av-1c-agentic-sdlc/SKILL.md).
Он определяет этапы работы, документы задачи и порядок работы с worktree.
Если навык не обнаружен автоматически, прочитай файл по этой ссылке.
Особенности текущего проекта определены ниже.

## Структура

- `src/cf` — основная конфигурация.
- `src/cfe/<target>` — расширения. Анализируй их вместе с основной конфигурацией.
- `tasks/YYYY-MM/<ключ>-<имя>` — документы задачи; ключ Jira и краткое имя на русском языке.
- `src/epf` и `src/erf` — исторические файлы. Не используй без указания пользователя.

## Рабочее окружение

- Изменения исходников выполняй в отдельном worktree задачи; существующий worktree используй повторно.
- Перед созданием прочитай проектную инструкцию и используй wrapper, если он есть. Для анализа и ревью worktree создавать не нужно.
- Базовую ветку, upstream и имя ветки задачи определяй по настройкам проекта. Не обновляй основную ветку без проверки состояния и разрешения на требуемые операции.
- Не убирай чужие изменения через stash, reset или удаление. Не удаляй worktree и ветки без разрешения.
- Профиль `bsl-analyzer.toml` должен охватывать нужные CF и расширения. Проверь фактический workspace и корень текущего worktree.

## Границы

- Не меняй чужие файлы вне задачи. Не выводи секреты.
- Push и помещение в хранилище выполняй только по разрешению.
- Загрузка конфигурации в ИБ, обновление БД и запись или удаление данных при проверках требуют явного разрешения в соответствующем объёме.
- Live-код выполняй только в явно разрешённой тестовой ИБ. Статический анализ не заменяет запуск 1С; указывай невыполненные проверки.
