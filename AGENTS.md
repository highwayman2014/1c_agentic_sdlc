# Правила проекта 1С

Для задач разработки 1С используй навык `av-1c-agentic-sdlc`:
[SKILL.md](.agents/skills/av-1c-agentic-sdlc/SKILL.md).
Навык описывает процесс, документы задачи, выбор навыков и работу с MCP.
Настройка инструментов и проверки также описаны в навыке.
Если навык не обнаружен автоматически, прочитай файл по этой ссылке.
Особенности текущего проекта определены ниже.

## Структура

- `src/cf` — основная конфигурация.
- `src/cfe/<target>` — расширения. Анализируй их вместе с основной конфигурацией.
- `tasks/YYYY-MM/<ключ>-<имя>` — документы задачи; ключ Jira и краткое имя на русском языке.
- `src/epf` и `src/erf` — исторические файлы. Не используй без указания пользователя.

## Рабочее окружение

- Для изменения исходников выбери обычную ветку или отдельный worktree по условиям задачи.
- Учитывай выбор пользователя, состояние рабочей папки и правила проекта.
- Существующее окружение задачи используй повторно после проверки состояния.
- Перед созданием ветки или worktree прочитай проектную инструкцию. Если есть подходящий wrapper, используй его.
- Для анализа и ревью создавать ветку или worktree не нужно.
- Базовую ветку, upstream и имя ветки задачи бери из настроек проекта.
- Перед обновлением основной ветки проверь её состояние и разрешение на операцию.
- Не убирай чужие изменения через stash, reset или удаление.
- Ветки и worktree удаляй только по разрешению.
- В `bsl-analyzer.toml` укажи нужные CF и расширения.

## Границы

- Не меняй чужие файлы вне задачи. Не выводи секреты.
- Push и помещение в хранилище выполняй только по разрешению.
- Для загрузки конфигурации и обновления БД получи разрешение на каждую операцию.
- Для записи или удаления данных при проверках получи отдельное разрешение.
- Live-код выполняй только в разрешённой тестовой ИБ.
- Указывай проверки, которые не выполнены.
