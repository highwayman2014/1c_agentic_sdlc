# Настрой MCP проекта

С 02.11.2026 СММ использует единое подключение `bsl`.
Оно предоставляет справку, анализ исходников и live-инструменты.
Общая обёртка: `scripts/mcp_profile.py bsl-unified`.
Источник выбирается по `CLAUDE_PROJECT_DIR` или папке запуска.
Обёртка ищет ближайший `bsl-analyzer.toml` до границы Git.
Без TOML используется пустой служебный источник для справки и live-инструментов.
В этом режиме нельзя делать выводы об исходниках проекта.
Codex получает явный `cwd` в проектном конфиге с тем же именем `bsl`.
У других проектов прежние профили сохраняются до отдельной миграции.

Глобальная установка: `python scripts/install_unified_bsl.py --apply`.
Применение текущего проекта: `python scripts/configure_mcp.py --workspace <путь> --client all --apply-shared --apply`.
Скрипты сохраняют резервные копии и настройки других серверов.
После применения перезапусти клиент или переподключи MCP.

Генерация эмбеддингов в едином профиле отключена.
Проверяй актуальность overlay по [search-index.md](search-index.md).
Подключение к ИБ всегда выбирай явно через `connection`.

Назначение навыков и MCP описано в [tools.md](tools.md).
Готовые файлы находятся в `D:\repository\1c_agentic_sdlc\mcp`.

Перед настройкой прочитай нужную инструкцию:

- Общие профили и проверка путей: [mcp-setup.md](mcp-setup.md).
- Нативный pi и Claude Code: [mcp-clients.md](mcp-clients.md).
- HTTP-расширение и live-инструменты 1С: [live-1c.md](live-1c.md).

Для проверки используй `scripts/configure_mcp.py --workspace <путь> --check`.
Для применения выбери `--client codex`, `--client pi` или `--client claude`.
Команды выполняй из общего репозитория.

В worktree анализатор должен читать исходники этого worktree.
Проектная wiki должна указывать на исходный проект.
Персональная wiki остаётся общей.
Используй общую установку анализатора через обёртку.
Не закрепляй отдельную версию для каждой задачи.
Используй общий базовый индекс и отдельный слой изменений worktree.
Порядок подготовки и ограничения описаны в [search-index.md](search-index.md).
Не открывай один изменяемый SQLite-кеш из разных рабочих папок.
Секреты храни в локальных env-файлах вне Git.

| Клиент | Проектный файл |
|---|---|
| Codex | `.codex/config.toml` |
| Нативный pi | `.pi/mcp.json` |
| Claude Code | `.mcp.json` |

Для pi используй встроенный MCP. Адаптер не требуется.
После применения проверь фактические серверы, корни и обе wiki.
Готовность подсистем анализатора проверяй отдельно.
При смене настроек проверь, не удерживает ли кеш прежний backend.
Наличие live-инструмента не разрешает работу в ИБ.
