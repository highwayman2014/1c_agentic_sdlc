# Настрой MCP проекта

Назначение навыков и MCP описано в [tools.md](tools.md).
Готовые файлы находятся в `D:\repository\1c_agentic_sdlc\mcp`.

Перед настройкой прочитай нужную инструкцию:

- Общие профили и проверка путей: [mcp-setup.md](mcp-setup.md).
- Нативный pi и Claude Code: [mcp-clients.md](mcp-clients.md).

Для проверки используй `scripts/configure_mcp.py --workspace <путь> --check`.
Для применения выбери `--client codex`, `--client pi` или `--client claude`.
Команды выполняй из общего репозитория.

В worktree анализатор должен читать исходники этого worktree.
Проектная wiki должна указывать на исходный проект.
Персональная wiki остаётся общей.
Используй общую установку анализатора через лаунчер.
Не закрепляй отдельную версию для каждой задачи.
Не смешивай кеши основной папки и worktree.
Секреты храни в локальных env-файлах вне Git.

| Клиент | Проектный файл |
|---|---|
| Codex | `.codex/config.toml` |
| Нативный pi | `.pi/mcp.json` |
| Claude Code | `.mcp.json` |

Для pi используй встроенный MCP. Адаптер не требуется.
После применения проверь фактические серверы, корни и обе wiki.
Готовность подсистем анализатора проверяй отдельно.
При смене настроек проверь, не удерживает ли кеш прежний backend.
Наличие live-инструмента не разрешает работу в ИБ.
