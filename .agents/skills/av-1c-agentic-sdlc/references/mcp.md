# Настрой MCP проекта

Используй единое подключение `bsl` для справки, исходников и live-инструментов.
Выбор исходников и выбор ИБ независимы.
Правила live-вызовов описаны в [live-1c.md](live-1c.md).
Правила индексов описаны в [search-index.md](search-index.md).

## Выбери конфиги

Пути установки и сервисов задаёт `mcp/runtime.json` общего репозитория SDLC.
Ключи проектов и основные рабочие папки задаёт `mcp/projects.json`.
Состав исходников задаёт `bsl-analyzer.toml` рабочей папки.
Подключения к ИБ задаёт `mcp/onec-connections.json`.
Источники локальных учётных данных задаёт `mcp/onec-credential-sources.json`.
Политику запуска общего baseline задаёт `mcp/baselines.json`.
Особенности проекта бери из его `AGENTS.md`.
Не добавляй имена проектов и пути рабочих папок в общий навык или скрипты.

## Установи подключение

Команды выполняй из общего репозитория SDLC:

```powershell
python scripts/install_unified_bsl.py --apply
python scripts/configure_mcp.py --workspace <путь> --check
python scripts/configure_mcp.py --workspace <путь> --client all --apply-shared --apply
```

Установщик сохраняет настройки других серверов и резервные копии.
Имена заменяемых серверов задаёт `retired_bsl_servers` в runtime-конфиге.
Для проверки без изменения файлов убери `--apply` у глобального установщика.
Для генерации проектных файлов без применения используй `--output <каталог>`.
Для отдельного клиента выбери `--client codex`, `pi` или `claude`.
После применения переподключи MCP или перезапусти клиент.

## Проверь рабочую папку

Обёртка использует `CLAUDE_PROJECT_DIR` или папку запуска.
Она ищет ближайший `bsl-analyzer.toml` до границы Git.
Codex получает явный `cwd` в проектном конфиге с тем же именем `bsl`.
Без TOML используется пустой служебный источник для справки и live-инструментов.
В этом режиме нельзя делать выводы об исходниках проекта.
Состояние рабочей папки проверяй по фактическим корням ответов MCP.

В worktree исходники должны принадлежать этому worktree.
Проектная wiki должна указывать на исходный проект.
Персональная wiki остаётся общей.
Используй общий baseline и отдельный изменяемый кеш рабочей папки.
Не открывай один изменяемый SQLite из разных рабочих папок.
Генерация эмбеддингов в единой обёртке отключена.
Проверяй полноту overlay отдельно от готовности сервера.

Порядок настройки клиентов: [mcp-clients.md](mcp-clients.md).
Проверка установки: [mcp-setup.md](mcp-setup.md).
